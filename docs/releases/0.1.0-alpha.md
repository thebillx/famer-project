# 0.1.0-alpha Release Notes

## Features

- Agent governance, task brief, handoff, workflow, and review structure.
- Backend foundation package layout for FastAPI development.
- Settings validation, error response shape, request ID middleware, structured logging helpers, and security headers.
- Authentication, RBAC, tenant-scope, and refresh-session foundation.
- Permanent engineering review infrastructure.

## Architecture

- Architecture, data flow, ER model, API contract, security model, and deployment guidance are documented.
- Work continues through contract-first vertical slices.
- OpenCode and GLM workflows are not part of the current project workflow; Codex is the active workflow.

## Security

- Production settings reject missing critical secrets, known development secrets, and insecure cookie configuration.
- API error responses avoid internal stack traces.
- Tenant-owned access must use organization scope.
- Satellite analysis language remains constrained to inspection guidance, not diagnosis.

## Database

- Alembic migration structure is present.
- Initial foundation revision covers users, organizations, memberships, and refresh sessions.
- Existing broader schema reference remains available for future slices.

## Testing

- Unit tests cover geospatial formulas, quality gates, safe language, settings, security tokens, refresh-session behavior, RBAC, and tenant scope.
- Contract tests cover OpenAPI and migration contract expectations.
- CI runs unit tests, contract tests, whitespace checks, JSON validation, and YAML validation when PyYAML is available.

## Known Limitations

- Full runtime API tests are not yet executed in a dependency-installed environment.
- Alembic upgrade/downgrade has not been executed locally because the host does not have Alembic installed.
- `ruff` and `mypy` are reported as `NOT_RUN` when unavailable.

## Not Implemented

- FIELD-001 and later field management features.
- Copernicus provider integration.
- Provider mock.
- Satellite analysis, overlays, anomaly detection, alerts, reports, dashboard, frontend, worker, scheduler, and production deployment automation.
